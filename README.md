# Customer-Churn-and-Retention-Analysis

## Project Overview

This project analyzes customer data to understand churn and retention patterns and identify factors that may be associated with customer churn.

The analysis was performed using Python, Pandas, and Power BI.

## Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Power BI
- DAX
- Data Visualization
  
## Skills Demonstrated

- Data Cleaning
- Data Analysis
- Exploratory Data Analysis (EDA)
- Data Visualization
- KPI Analysis
- Churn & Retention Analysis
- Outlier Analysis
- Dashboard Development

## Dataset

The dataset contains 700 customer records with information related to:

- Customer ID
- Age
- Tenure Months
- Contract Type
- Monthly Charges
- Usage Hours
- Support Tickets
- Churn Status
- Customer Satisfaction

## Data Cleaning & Preparation

The data was prepared and validated using Python and Pandas.

The following steps were performed:

- Checked for missing values
- Checked for duplicate records
- Verified data types
- Identified potential outliers using the IQR method
 
## Key Insights

- The dataset contains 700 customer records, with 256 customers classified as churned and 444 retained.
- The overall churn rate is approximately 36.6%, while the retention rate is approximately 63.4%.
- Customer churn was analyzed in relation to tenure, monthly charges, usage hours, support tickets, and customer satisfaction.
- Outlier analysis was performed to identify unusual customer-level values that could affect the analysis.

## Recommendations

- Focus retention efforts on customer groups showing higher churn levels based on the analyzed customer attributes.
- Monitor customer satisfaction and support-ticket patterns to identify customers who may require additional support.
- Pay closer attention to customers with potentially higher churn risk and consider targeted retention strategies.
- Regularly track churn and retention KPIs through Power BI to monitor changes over time.
